#Stardew-Valley-Save-Folder-Shortcut
Stardew Valley Save Folder Shortcut - Мод облегчающий поиск папки с сохранениями.
С помощью данного мода вы можете перейти к папке с сохранениями не лазая в недры системы, что значительно облегчает установку и удаление ненужных вам сохранений, или с целью резервирования для дальнейшего хранения на навше жестком диске, флэшки и так далее.
Основные функции данного мода:
- Быстрый доступ к файлам сохранения из главного меню 
- Окно, которое появляется после обнаружения установленного сохранения игры
- При нажатии кнопки "Да, перезапустить", игра автоматически перезапускается, чтобы отобразить ваше сохранение. 
- При нажатии кнопки "Нет, продолжить" игра не станет перезапускаться, чтобы вы могли продолжить игру.

Все исходники будут находиться в репозитории, чтобы вы могли сделать мод под себя.
