# Stardew-Valley-Save-Folder-Shortcut
Stardew Valley Save Folder Shortcut - A mod that makes it easier to find the save folder.
This mod allows you to access your save folder without digging through system directories, making it much easier to install or delete saves, or to back them up to your hard drive, a flash drive, etc.
Key features of this mod:
- Quick access to save files from the main menu
- A window that appears after a game save is detected
- Clicking "Yes, restart" automatically restarts the game to load your save
- Clicking "No, continue" skips the restart, allowing you to keep playing
The source code is available in the repository, so you can customize the mod to your liking.
